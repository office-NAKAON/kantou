# 関東地方「東京は50年後も日本の中心か」

中学校第2学年の社会科（地理的分野）で使う、生徒用のOPPアプリです。

中心の問いは、次の1行です。

**東京は50年後も日本の中心として持続可能だろうか？**

知識の習得は授業で行います。アプリが担うのは、学習前の答え、5回の「判断 → 一対一の話し合い」、学習後の答え、学習前との比較です。

5回の見方は、自然、機能、空間、産業、地域です。各回で一対一を2回行い、相手は全部で10人、必ず別人です。出席が奇数で1人余るときは、その相手が先生になります。先生はアプリを操作しません。

APIキーは使いません。生徒の書き込みは、先生のGoogleスプレッドシートに残ります。

## 公開する

1. Googleスプレッドシートを新しく作ります。
2. 拡張機能から Apps Script を開きます。
3. `コード.gs` の中身を、このリポジトリの `gas/Code.gs` に差し替えます。
4. 「＋」から HTML を追加し、ファイル名を `Index` にします。中身は `gas/Index.html` です。
5. デプロイで新しいデプロイを作り、種類はウェブアプリにします。実行するユーザーは「自分」、アクセスできるユーザーは「全員」です。
6. 表示されたURLを生徒に配ります。

スプレッドシート本体は生徒に共有しません。配るのはウェブアプリのURLだけです。

学校の設定で「全員」が選べないときは、アクセスできるユーザーを、学校のGoogleアカウントを持つ全員にします。

画面や保存の処理を直したあとは、新しいデプロイを作り直します。古いURLのままでは、直した内容は生徒に届きません。

## スプレッドシート

最初にウェブアプリを開くと、次の2枚が作られます。1行目の見出しは変えないでください。

| シート | 残るもの |
|---|---|
| 生徒 | 組、番号、氏名、学習前、学習後、比べたこと |
| 判断 | 回、見方、最初の立場と理由、話した相手2人、話し合いのあとに残した判断 |

相手の組み合わせは、同じクラスで、その回の判断を書き終えた生徒同士です。ほかのクラスとは組みません。待ち画面は、約5秒ごとに相手が決まったかを確認します。

## 生徒の入り方

組、出席番号、氏名で自分のOPPを開きます。パスワードはありません。同じ組・出席番号・氏名なら、別の端末から続きを書けます。出席番号が同じで氏名が違う場合は開けません。

## ファイル

| ファイル | 役割 |
|---|---|
| `youken.md` | 要件定義 |
| `gas/Code.gs` | スプレッドシートへの保存と、相手の割り当て |
| `gas/Index.html` | 生徒の画面 |
| `gas/appsscript.json` | GASの設定 |
| `index.html` `server.js` | このパソコンだけで画面を確認するためのもの |

このパソコンだけで画面を見るときは、`node server.js` を実行し、表示されたURLを開きます。そのときの記録はスプレッドシートには残りません。
