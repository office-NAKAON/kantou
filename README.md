# 関東地方「東京は50年後も日本の中心か」

中学校第2学年の社会科（地理的分野）で使う、生徒用のOPPアプリです。画面の見出しは「デジタルOPPシート」です。

中心の問いは、次の1行です。

**東京は50年後も日本の中心として持続可能だろうか？**

知識の習得は授業で行います。アプリが担うのは、学習前の答え、5回の「判断 → 一対一の話し合い」、学習後の答え、学習前との比較です。

5回の見方は、自然、機能、空間、産業、地域です。各回で一対一を2回行い、相手は全部で10人、必ず別人です。その回の相手待ちが奇数で1人余るときは、その相手が先生になります。先生はアプリを操作しません。

APIキーは使いません。生徒の書き込みは、先生のGoogleスプレッドシートに残ります。

## 公開する

このリポジトリは、clasp でスプレッドシート付きのスクリプトに紐づいています。

画面や保存の処理を直したあとは、次の順です。

1. このフォルダで `clasp push` を実行します。
2. Apps Script のデプロイで、新しいデプロイを作ります。種類はウェブアプリ、実行するユーザーは「自分」、アクセスできるユーザーは「全員」です。
3. 表示されたURLを生徒に配ります。

古いURLのままでは、直した内容は生徒に届きません。スプレッドシート本体は生徒に共有しません。配るのはウェブアプリのURLだけです。

学校の設定で「全員」が選べないときは、アクセスできるユーザーを、学校のGoogleアカウントを持つ全員にします。

新しくスプレッドシートから作り直すときは、拡張機能の Apps Script に `gas/Code.gs` と `gas/Index.html` を入れ、同じ条件でウェブアプリとしてデプロイします。

## スプレッドシート

最初にウェブアプリを開くと、次の2枚が作られます。すでに生徒シートがあるときは、足りない「パスワード」列だけが足されます。1行目の見出しは変えないでください。

| シート | 残るもの |
|---|---|
| 生徒 | 組、番号、氏名、4桁のパスワード、学習前、学習後、比べたこと |
| 判断 | 回、見方、最初の立場と理由、話した相手2人、話し合いのあとに残した判断 |

生徒が使う前に、組、番号、氏名、4桁のパスワードを入れてください。学習前、学習後、比べたことは空欄のままにします。ここを先に書くと、生徒が書いたことになります。

相手は、同じクラスで、その回の判断を書き終えて相手待ちになっている生徒同士です。画面を開いているかどうかでは選びません。ほかのクラスとは組みません。待ち画面は、約5秒ごとに相手が決まったかを確認します。

## 生徒の入り方

生徒は組を選び、その組の名簿から氏名を選び、4桁のパスワードを入れてOPPを開きます。名簿にない氏名は選べません。パスワードを5回間違えると、しばらく開けません。

同じタブを開き直したときは、パスワードを入れ直さなくてよいです。タブを閉じたときや別の端末では、同じ組・番号・氏名とパスワードでもう一度入ります。書いた内容はスプレッドシートに残っているので、続きから書けます。

## ファイル

| ファイル | 役割 |
|---|---|
| `youken.md` | 要件定義 |
| `gas/Code.gs` | スプレッドシートへの保存と、相手の割り当て |
| `gas/Index.html` | 生徒の画面 |
| `gas/appsscript.json` | GASの設定 |
| `.clasp.json` | clasp が送る先のスクリプト |
| `index.html` `server.js` | このパソコンだけで画面を確認するためのもの |

このパソコンだけで画面を見るときは、`node server.js` を実行し、表示されたURLを開きます。氏名の一覧は `data/store.json` の `roster` です。そのときの記録はスプレッドシートには残りません。
